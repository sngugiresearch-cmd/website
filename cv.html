Selected Projects & Technical Writing

Formally Verified C RL environment · formal verification
  • Designed and released an RL environment where models complete C functions under immutable ACSL contracts and earn staged reward from Frama-C proofs of functional correctness and runtime safety—not sampled tests.
  • Built the 64-task Core-v1 corpus and its trust boundary: an isolated, version-pinned judge; fail-closed verdict parsing and caching; adversarial negative controls; reproducible proof evidence; and public Prime, Hugging Face, and GHCR artifacts. The exact v0.1.7 Hub source passed 57/57 tests.
  • Article: An RL Environment Where C Code Has to Be Proved, Not Just Tested.
MathCheck RL & MathCheck Engine RL environment · Lean verification
  • Designed answer-key-free math RL tasks whose prompts and Lean checks derive from the same frozen bounded specification; models submit ordinary answers or complete pair certificates rather than proof scripts.
  • Built the reusable verifier for exact evaluation, bounded sums, counts, minima, and complete pair relations, with cost-bounded inputs, isolated Lean 4.23.0 execution, digest-bound evidence, and typed mathematical versus operational failures. The release passed 71 tests and 42 generated real-Lean subtests.
  • Articles: How MathCheck RL Replaces Hidden Answer Keys with Lean-Checked Rewards and Building a Lean-Backed Verifier for Bounded Mathematical Answers.
Grammars for AI-Generated Mathematical Proof Steps research + code
  • Built and audited a Lean tactic grammar with executable counterexamples, corpus-extraction analysis, and 6,413 mutation and prose probes; showed how a broad fallback produced high corpus coverage while rejecting only 3.41% of those probes.
  • Ran a paired-prompt Qwen2.5-Coder-7B study with 640 samples per condition: grammar masking raised first-line CFG acceptance from 65.6% to 100% and familiar tactic starts from 60.2% to 91.3%, while keeping the boundary between grammar membership and Lean correctness explicit.
  • Articles: Building a Grammar for AI-Generated Mathematical Proof Steps and How a Grammar Changes AI-Generated Mathematical Proof Steps.
Taming Incidental Polysemanticity in Toy Models technical study
  • Built overcomplete toy networks and sparse autoencoders to test whether feature entanglement is shaped during model training; across ten seeds, an L2+GELU configuration showed 17.9% lower interference than L1+ReLU, motivating a configuration-level hypothesis rather than an isolated L2-effect claim (code).
